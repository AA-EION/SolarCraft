# SolarCraft

A planned offline-first desktop application for photovoltaic design, simulation, storage and financial analysis, with native shells on Windows (WinUI 3) and macOS.

**Status: foundation approved; technical spikes in progress.** Read [docs/decisions/0001-foundation.md](docs/decisions/0001-foundation.md) and [docs/discovery/](docs/discovery/README.md).
